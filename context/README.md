# Context notes

One file per client, named after its slug (`vnsh.md`, `pain-safari.md`, ...).

Before a mid-month or end-of-month run, the account lead adds anything the data can't
explain for that period, for example:

- a promotion, coupon or price change and its dates
- a suspension, appeal or listing issue
- a stock-out caused by the supplier, not demand
- clearance pricing

Keep each note to a line, with dates. The report uses these to explain movers instead of
guessing. Remove notes once they no longer apply.
